# Multi-image method

Use when two or more images are supplied. Run Step 1 (sweep) on **each image separately**, using
IDs prefixed by the image: `O1.1` (image 1, obs 1), `O2.7`, etc. Seal all ledgers, then do the
cross-image pass. Cross-image findings are deductions and follow the same citation rules.

## Cross-image checks
1. **Same-subject test** - do the images show the same room, person-owned objects, or location?
   List matching anchors (a unique stain, model, furniture, window shape) and any mismatches.
   Verdict: same / probably same / different / cannot tell, with confidence.
2. **Timeline ordering** - order the images by time using light, wear progression, clutter changes,
   battery/clock cues, seasonal cues, consumed items. State what each ordering depends on.
3. **Change detection** - what moved, appeared, disappeared, got used up, got dirtier or cleaner
   between images? A moved object is a story: who, why, how long between shots.
4. **Contradictions** - things that cannot both be true (shadows, weather, clock readings). Flag as
   a possible edit, a different day, or a different place.
5. **Accumulation** - several weak marks that point the same way across images can earn a higher
   confidence than any single image. Say which images contribute.
6. **Coverage gaps** - what none of the images show that would settle the main uncertainty.

## Output additions
- A short per-image synopsis (2 lines each) before the combined verdict.
- A "Cross-image findings" section after Deductions.
- In the ledger, group by image, then by category.

## Pitfalls
- Do not merge observations across images unless they are about the same object; keep IDs distinct.
- A cross-image conclusion must cite observations from at least two images.
- If images are clearly unrelated, say so and analyse them separately instead of inventing a link.
